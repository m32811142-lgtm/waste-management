# سامانه مدیریت و پایش مخازن پسماند شهری

این پروژه برای درس **کارگاه برنامه‌نویسی** طراحی شده است. هدف این سامانه، دریافت، اعتبارسنجی، تحلیل و نمایش موقعیت جغرافیایی مخازن پسماند شهری روی نقشه است.

## ویژگی‌ها
- خواندن اطلاعات مخازن از فایل CSV
- اعتبارسنجی داده‌ها (شناسه تکراری، مختصات نامعتبر، درصد پرشدگی خارج از محدوده و...)
- محاسبه حجم تقریبی پسماند و دسته‌بندی مخازن (عادی، نیازمند پایش، اولویت بالا)
- اولویت‌بندی مخازن بر اساس امتیاز وزنی
- تولید گزارش جامع و ذخیره در فایل CSV
- نمایش مخازن روی نقشه وب با استفاده از Leaflet و OpenStreetMap
- طراحی تست‌های خودکار با استفاده از Pytest

## الگوریتم اولویت‌بندی
اولویت هر مخزن با فرمول زیر محاسبه می‌شود:

$$P_i = w_1 \frac{F_i}{100} + w_2 S_i$$

که در آن:
- \(F\): درصد پرشدگی
- \(S\): امتیاز وضعیت (فعال بودن)
- \(w_1=0.7\) و \(w_2=0.3\): ضرایب وزنی
